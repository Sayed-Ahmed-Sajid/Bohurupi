# Bohurupi - Hotel & Tour Booking

React + Vite + Tailwind CSS + React Router DOM + Hooks.

## Run

```
npm install
npm run dev
```

Open http://localhost:5173

## Folders

- src/components : reusable UI parts (Navbar, Hero, cards, sections)
- src/pages : one file per route
- src/data : destinations, packages, hotels, FAQ, reviews
- src/context : WishlistContext (useContext)
- src/hooks : useLocalStorage (custom hook)
